## Course File

**Format:** CSV  
**Description:** Data based on students enrolled in one term only. Contains entire academic history for all students enrolled for specific term that are: BPA Major, or Enrolled in a BPA course.

| Fieldname    | Description                                                                                                                                                                  |
| :----------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MNUMBER      | Banner ID for Student                                                                                                                                                        |
| TERM         | Academic History Term for the course (YYYYSS, where SS=term) <br> \*SS=10=Spring Term (example 201010), SS=50=Summer Term (example 201050), SS=80=Fall Term (example 201080) |
| PARTOFTERM\* | Part of Term Code for course (i.e. first-half semester course)                                                                                                               |
| CRN          | Course Reference Number (Registration Number) for course                                                                                                                     |
| CRSESUBJ     | Course Prefix (i.e. ACC, ENG)                                                                                                                                                |
| CRSENUMB     | Course Number (contains leading zeros for courses <100; i.e. 099)                                                                                                            |
| SECTION      | Course Section (contains leading zeros for sections <10; i.e. 03)                                                                                                            |
| CRHRS        | Course Credit Hours (99.9 format)                                                                                                                                            |
| LEVLCODE     | Course Level (UG=Undergraduate, GR= Graduate, ES=ESL)                                                                                                                        |
| RSTSCODE\*   | Most Recent Registration Code for Course                                                                                                                                     |
| INSMCODE\*   | Instructional Method for Course                                                                                                                                              |
| LASTATTEND   | Last Attendance Date for student in that course, as entered by instructor                                                                                                    |
| MIDGRADE     | Midterm Grade given by instructor                                                                                                                                            |
| FINGRADE     | Final Grade given by instructor                                                                                                                                              |
