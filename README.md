# Tech Stack

- **Framework**: React 19
- **Meta-Framework**: TanStack Start
- **Language**: TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn UI
- **Routing**: TanStack Router
- **Data Fetching**: TanStack Query
- **Database**: MySQL with Drizzle ORM
- **Authentication**: Better Auth
- **Testing**: Vitest
- **Linting**: OxLint
- **Formatting**: Prettier
